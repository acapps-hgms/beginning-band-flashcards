# Holly Grove Bands — Note Flashcards

This folder is ready for static web hosting. No image folder or external assets are required.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Run locally
Double-click `index.html` and open it in Chrome, Edge, or Safari.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload these three files to the top level of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. Use the published GitHub Pages URL in Canvas or on your class website.

## Editing note sets
The note sets are at the top of `app.js`. Make a backup before editing.

## Fingering diagrams
The site draws its own simple SVG fingering schematics in the browser. It does not redistribute the Yamaha or Ken Moran chart images that were used as classroom references during development.

Before classroom use, compare every fingering with the exact convention and method sequence you teach.
