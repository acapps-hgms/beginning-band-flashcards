# Fingering references

The student website does not contain or redistribute the source fingering-chart images.

During development, classroom reference charts supplied by the teacher included:
- Yamaha flute and clarinet fingering charts
- Ken Moran, 2019, beginningsaxophone.com, alto saxophone fingering chart

The app uses original, simplified SVG schematics drawn by JavaScript. Verify the fingerings against the exact method and fingering conventions used in class before publishing.
